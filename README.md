# Celest
Chords the *algorithmic* way. Add as many MIDI devices as you want and easily voice them across each chord, generated on the fly.

# Demo
Seven minutes of Celest: https://youtu.be/KAduKS02p-w
<br />
<sub>Uses loopMIDI and a few Kontakt instances to create a huge sound.<sub>

# To install
Clone the repo
Run `npm run dev`
